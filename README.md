# Weather App

A responsive weather app that shows live weather and a 5-day forecast for any city.

## Features

- Search any city by name (button click or Enter key)
- Current temperature, weather condition, humidity, wind speed and pressure
- 5-day forecast cards
- Loading spinner and error message for invalid cities
- Background changes with the weather (sunny, cloudy, rainy, snow, night)
- Fully responsive for mobile and desktop

## Built With

- HTML
- CSS (Flexbox, animations, media queries)
- JavaScript (Fetch API, async/await)
- OpenWeatherMap API
